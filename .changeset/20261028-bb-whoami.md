working-with-bitbucket-api: `bb whoami` prints the authenticated Bitbucket account and where its credentials come from, one fact per line: `nickname`, `display_name`, `account_id`, `credentials` (`BB_TOKEN env` or `keychain (com.quatico.bitbucket-cli)`). It never prints the token or the email, and exits 1 when no credentials work. `bb auth status` runs the same code. Both `--json` forms now print `{nickname, display_name, account_id, uuid, credentials}` instead of the raw `/user` body; `bb api /user` still returns the raw body. Before, `bb whoami` answered `unknown command: whoami`.
